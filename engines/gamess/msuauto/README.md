The CCSDt, CC(t;3), ACP, and DEA/DIP-EOMCC methods implemented by the group
of Piotr Piecuch at Michigan State University, East Lansing, Michigan, USA
with the help of the automated formula derivation and computer implementation
software developed by Jun Shen (see CCTYP = CCSD3A, CCT3, ACCSD, ACC23, ACCSD3A,
ACCT3, DEAEOM2, DEAEOM2A, DEAEOM3, DEAEOM3A, DEAEOM3B, DIPEOM2, DIPEOM3, and
DIPEOM3A).

Authors: Jun Shen, Adeayo O. Ajala, J. Emiliano Deustua, Ilias Magoulas, and
Piotr Piecuch.
