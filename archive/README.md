# Historical engineering snapshot

`legacy_fmo87_20261020/` preserves the repository tree from commit
`7b99ca7bbc47a5d66ac4d40daf99cc13f33c390d` before the maintained toolkit was
installed at the root. Its 9,141 tracked files are verified in
`LEGACY_MANIFEST.json`, including symbolic-link targets. Git history is not rewritten.

This is historical material, **not the current default workflow**. Some historical
files include third-party software, benchmark inputs and machine-specific paths.
Their existing restrictions still apply. Moving them here does not grant new
redistribution rights. Do not make this repository public without reviewing those
rights and its existing Git history.

Start at the root `README.md` or `README.zh-CN.md` for the maintained tool.
Historical binaries/data are not dependencies of the current Python distribution
and are excluded from wheel, sdist and the clean source archive.
