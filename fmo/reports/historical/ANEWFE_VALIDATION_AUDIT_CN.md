# AnewFE / AnewFEP 方法迁移审计

日期：2026-10-04。现已识别用户所指为 AnewFEP 预印本：Wentao Li 等，
“Physics-Based vs AI-Based Free Energy Prediction for Protein-Ligand Potency: Public
Benchmarks and Internal Project Evidence”，ChemRxiv DOI `10.26434/chemrxiv.15002526.v2`
(2026-06-02)。本机留存的 v2 PDF 已逐页核对（文件位于工作区父目录，29 页）。文中方法、
参数和案例结论以下述 PDF 正文为依据，而非仅摘要。它是 GROMACS/AnewFF/REST2 的
相对结合自由能（RBFE）流程；不是 GAMESS FMO 端点能量，也不能直接移植其数值参数。

正文报告的协议要点包括：Amber ff14SB 蛋白、AnewFF 配体、TIP3P 显式水、0.15 M 盐；
能量最小化后进行有位置约束的 NVT/NPT 松弛、无约束 NPT 平衡，再进行 20 ns 生产采样，
以 3 个随机种子独立重复。按变换类型使用 24 或 32 个 λ 窗口；REST2 热区默认是变异原子，
其有效温度调度按约 0.3 的 replica-exchange 期望接受率设计。多个质子化态和 rotamer
可进入状态集，并通过 pKa/rotamer correction 处理。论文还将 phase-space overlap、
自由能收敛、结构稳定性、交换接受率，以及相互作用和扭转分布作为自动质量/机理诊断。

正文的数值工程改进包括：确定性双精度 GPU reduction 以消除 A→A 非零漂移；避免
λ→0 奇异性的 soft-bond；对变异 A/B/共有原子独立缩放 λ 及 charge-changing 的
co-alchemical waters；以及 MTS、HMR 和远程 Ewald exclusion 修正。这些解决的是 RBFE
实现问题，不是 FMO/PBSA 的现成参数。

## 可迁移的原则

正文通过方法和案例分析多种可分离的物理/数值失效因素。对本项目有用的迁移边界是：

1. **输入结构是模型的一部分**：蛋白标准化、质子化、配体参数、显式水、姿态和
   旋转异构体必须冻结并可追溯；不能把坏姿态的能量误认为方法本身的能力。
2. **失败模式要拆开处理**：采样不足、局部构象陷阱、参数化误差、蛋白柔性和
   λ/ restraint 设置不是同一个问题，不能只调一个总权重掩盖它们。
3. **公共集上的回顾性改进不等于盲测**：即使协议没有实验标签回归，基于已知
   失败案例修改力场或调度仍属于回顾性开发；真正的迁移证据要靠新靶点或
   prospective 数据。

## AnewFEP 到 FMO 的方法映射

| AnewFEP 正文中的对象 | 对 FMO 流水线可迁移之处 | 不能直接照搬之处 |
|---|---|---|
| 小分子力场局部修正 | 对配体电荷、价态、键级、氢原子和 FMO fragment mapping 做逐例审计；若异常则按 target 统一修复并重算全组 | ML 力场参数不能直接替换 GAMESS/FMO Hamiltonian；不可按已知活性配体挑选参数 |
| 蛋白构象控制 | 通过 receptor/pocket、侧链、水网络和 restraint 因子臂量化结构敏感性；比较完整配体组上的分支一致性 | 静态 FMO 结构或少量结构臂不等价于蛋白构象系综或自由能采样 |
| REST2 采样 | 对 torsion/构象状态做独立 replica、block、ESS、分布稳定性审计；未收敛就延长采样 | E61 当前只测配体二面角边缘分布；未包含完整蛋白/溶剂/平移转动熵，也不是 REST2 |
| alchemical schedule / 数值稳定性 | FMO 对应审计 SCF 收敛、fragment topology、PCM/PBSA 状态一致性和重复结构的数值闭合 | FMO 端点相互作用分数没有 λ 路径；不能把 λ schedule 技巧或三态端点差直接等同 RBFE |

### 可迁移的案例逻辑

论文的案例不是“对所有体系统一加一个项”，而是先诊断误差源，再做能隔离该误差的对照：

- **HIF-2α：局部非键参数问题。** SO₂ 氧的 Lennard–Jones 尺寸调整改善系列级预测；FMO 的对应动作应是审计特定化学环境的电荷/基组/fragment 映射与接触敏感性，并在 target/化学系列层冻结修改，不能据活性标签调单个配体。
- **BACE1：键合扭转问题。** 对一个近热中性变换，原力场扭转项造成约 −2 kcal/mol 的假稳定；FMO 可先比较结合态与游离配体几何、扭转分布和多起点构象能，但单个 MM torsional penalty 不可直接当作 FMO 熵或结合自由能。
- **FXa：蛋白构象响应。** backbone restraint 改变 Gly219 羰基朝向和接触距离并改善 RBFE；FMO 的迁移实验是对同一 target 统一定义受体/侧链/骨架构象臂，并按结构漂移触发，不能逐配体挑使排序最好的受体。
- **JNK1：局部 rotamer 与采样路径。** 芳环翻转导致局部极小值，初始构象和路径决定采样；FMO 应生成两种预定义 pose/rotamer 并全部评分、检查构象占比/跨臂差异，不能只保留最低能或最好相关的 pose。

这些例子支持“结构诊断决定要计算哪些对照臂”，不支持“仅用无标签结构即可知道哪一能量分数与亲和力方向一致”。因此无标签流程必须允许 `REVIEW/UNCERTAIN`，将精度主张留给独立 target 或 prospective 验证。

因此迁移的核心不是“把 tPIE、ES、溶剂项和熵都加起来”，而是**分层定位失败源、
控制输入/数值误差、采样达到稳定后再比较预先定义的物理量**。采样得到多个构象时，
若只做描述性排序，可以报告按系综权重的平均分及其不确定度，但必须称为 ensemble
score；真正的自由能需要一致哈密顿量下的配分函数/重加权，例如
\(\Delta G=-k_BT\ln\langle e^{-\beta\Delta U}\rangle\)，且需验证能量定义和
态间重叠。当前各 FMO/PBSA/PCM 输出尚未满足这套重加权闭合条件，故不能把它们
直接代入该式或声称得到完整 ΔG。

## 与当前 FMO 的边界

当前 FMO 的 `tPIE` 是复合物中蛋白–配体 PIEDA pair 的端点相互作用分数：

\[
 tPIE = ES + EX + CT + DI + SOLV.
\]

`ES+SOLV` 是上述分解的嵌套子集，而不是可以再加到 `tPIE` 上的独立自由能。
三态差值、PBSA、PCM 和熵可以作为额外物理诊断，但只有在状态定义、溶剂模型和
参考态一致时才允许构造自由能代理；否则必须保持为独立候选分支。

因此本项目采用三层证据：

| 层级 | 允许的表述 | 当前实现 |
|---|---|---|
| 直接端点分数 | 无标签 FMO interaction ranking | `tPIE`、`ES+SOLV` 等独立分支 |
| 校准分数 | 在明确训练/验证切分下的预测器 | 只作敏感性/泛化实验 |
| 自由能方法 | 有完整 bound/free 状态、采样和标准态处理 | 当前尚未完成，熵不收敛时不得宣称 |

## 当前生产规则

- 先做全靶点结构质控、统一修复和最小化后审计；所有配体使用同一规则。
- 结构修复或姿态敏感时运行 `k=1/10/100` 三个 blind arm；仅用稳定性检测
  数值不确定性，不把稳定性当作准确性证明。
- `tPIE`、`ES`、`ES+SOLV`、`ES+CT+SOLV` 先并行保存；不得直接相加嵌套项。
- 熵必须通过身份、完整轨迹、有效样本数和 split-half JS 门槛；不通过就追加
  预先声明的采样 block，预算耗尽仍不通过则标记 `OMIT`。
- 如果所有零拟合分支都没有正向证据，输出 `FMO_UNCERTAIN`，而不是为单个
  target 后验挑一个看起来最好的 PIEDA 子集。

这套规则避免把更多项盲目相加；项目已对本地 v2 正文中描述的局部参数、构象控制、
多状态和数值诊断逐项做迁移映射，但没有复现 AnewFEP，也不假装当前端点 FMO 等价于
完整 RBFE。后续仍需用已冻结的外部 target/前瞻数据检验这些迁移是否提高排序。
