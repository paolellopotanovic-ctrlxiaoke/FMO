# Galectin3 FMO 低相关根因分析

日期：2026-10-06。

## 结论先行

Galectin3 的低相关**不能仅归因于“配体构象预测错了”**，但构象/姿态处理确实是重要候选因素。当前证据更支持一个组合原因：

```text
固定单一复合物姿态的 FMO 相互作用能
≠
包含溶液态、结合态、构象布居、去溶剂化和熵的结合自由能
```

FEP+ 在同一 26 例上达到 `0.874/0.661`，说明该集合并非所有物理方法都不可预测；但 FEP+ 与 FMO 计算的物理对象不同，不能把 FEP+ 的高分解释为“它只用了同一构象但算得更精确”。

## 直接证据

| 观察 | 数值/结果 | 含义 |
|---|---:|---|
| FMO tPIE | `0.238/0.174` | 只有弱正向 |
| FMO ES | `-0.492/-0.449` | 静电项反向 |
| FMO ES+SOLV | `-0.434/-0.393` | 加 PCM 后仍反向 |
| FMO ES+CT+SOLV | `-0.414/-0.304` | 加 CT 后仍反向 |
| 官方 FEP+ | `0.874/0.661` | 同一集合上明显有效 |
| FMO k10→k100 | tPIE `0.238/0.174` → `0.200/0.238` | 改变约束不能恢复整体方向 |
| k10 配体重原子 RMSD | 中位约 `0.312 Å` | 整体位移不大，但不排除局部接触错误 |
| k10 最大配体位移 | 约 `1.37 Å` | 个别柔性基团发生明显局部移动 |
| PDBFixer | 无缺失残基/重原子 | 不是简单结构缺陷主因 |

## 构象是不是原因？

### 支持“构象有贡献”的证据

1. k1、k10、k100 三个统一 restraint 分支的结果不同，说明 FMO 对局部几何敏感。
2. Galectin3 有少数配体在最小化中局部位移较大，整体 RMSD 较小并不能保证氢键、芳香堆积和水介导接触相同。
3. FMO 是单一复合物姿态的固定几何能量；真实实验值对应多个溶液/结合构象的统计平均。
4. FEP+ 的官方结果经过相对自由能路径和构象/旋转异构体、对称性及 pKa/互变异构体相关后处理；这比单点 tPIE 包含更多状态平均。

### 不支持“只是构象错了”的证据

1. k1/k10/k100 都没有使 Galectin3 的 ES 类指标转正。
2. 去掉 4 个严重冲突水后，tPIE 从更差结果改善为弱正向，但 ES、ES+SOLV、ES+CT+SOLV 仍然反向。
3. PDBFixer 没有发现缺失残基或缺失重原子；结构输入不是明显损坏的 PDB。
4. 最小化位移与 FMO 残差的相关性很弱到中等：RMSD 与 tPIE 残差 Pearson 约 `0.31`，最大原子位移与 tPIE 残差约 `0.38`。这不能证明位移是主导变量。

所以当前判断是：

> 构象/姿态可能是重要贡献，但目前证据不足以称它是唯一或主导根因。必须做“同姿态换能量模型”和“多构象全纳入”两个对照才能定论。

## FMO 为什么会输给 FEP+？

### 1. 计算对象不同

当前 tPIE 是：

```text
一个固定 AB 复合物姿态中的蛋白–配体片段相互作用能
```

而实验亲和力更接近：

```text
ΔG_bind = G_complex − G_protein − G_ligand
```

并且每个 `G` 都包含构象布居、溶剂化、环境响应和熵等自由能贡献。

因此 tPIE 可以在某些集合上有效，但它不是严格结合自由能。

### 2. Galectin3 存在明显的系列/大小基线

Galectin3 里有 `17*` 和 `18*` 两个明显系列。FMO 的平均值为：

| 系列 | 平均 tPIE | 平均 ES+SOLV | 实验 ΔG 范围 |
|---|---:|---:|---:|
| 17 系列 | `-104.44` | `-57.05` | `-7.21` 到 `-4.10` |
| 18 系列 | `-101.70` | `-53.41` | `-7.46` 到 `-4.81` |

FMO 的溶剂相关分数与配体重原子数的 Pearson 相关约为 `0.83`，而实验 ΔG 与重原子数相关约为 `-0.39`。这说明 FMO 的绝对分数很容易把“分子更大、片段更多、接触项更多”当成更有利能量，但实验排序还要扣除配体自身溶液态、构象和去溶剂化代价。

### 3. 统一加更多 PIEDA 项没有解决问题

Galectin3 上：

```text
tPIE       +0.238 / +0.174
ES         −0.492 / −0.449
ES+SOLV    −0.434 / −0.393
ES+CT+SOLV −0.414 / −0.304
```

这说明问题不是“少加了某一个简单能量项”。加入 PCM、CT 或其它 PIEDA 项后，加入的变化反而主要体现为系列大小、极性和局部环境差异，并没有恢复实验排序。

### 4. FEP+ 的高分来自自由能差值和状态平均

FEP+ 不只是对一个 AB 姿态计算一次相互作用能。它通过一系列相邻配体之间的 alchemical transformation 求相对自由能，热力学积分/重加权过程中会对采样到的构象和环境状态进行平均；benchmark 的发布结果还包含构象、旋转异构体、对称性及 pKa/互变异构体相关处理。

这带来两个优势：

- 大的系统性绝对能量和分子大小基线在相对变换中更容易抵消；
- 配体柔性、溶剂和局部蛋白环境不是被一个固定几何点代表，而是进入自由能平均。

代价是 FEP+ 计算昂贵、依赖映射质量和采样收敛，且不能简单认为它在任何数据集都可靠。FXa set3 的 FEP+ 也反向，说明 FEP+ 并非万能。

## 目前最可能的根因排序

| 根因 | 证据强度 | 当前判断 |
|---|---|---|
| 单一固定姿态/缺少构象采样 | 中高 | 很可能贡献之一 |
| FMO tPIE 不是自由能，缺少配体溶液态和构象代价 | 高 | 主要根因之一 |
| 分子大小/系列基线未消除 | 高 | Galectin3 中证据明确 |
| 水处理错误 | 中 | 已修复一部分，但不是完整根因 |
| PDB 缺失残基/重原子 | 低 | 已基本排除 |
| 单独 k10 参数不合适 | 中低 | 不是唯一原因 |
| FMO Hamiltonian/PCM 数值实现错误 | 低 | 当前审计未发现；需同姿态对照进一步排除 |

## 最关键的后续实验

### 实验 A：同一姿态对照

对每个 Galectin3 配体固定同一套重原子 pose，只分别计算：

1. FMO tPIE/PIEDA；
2. MM/GBSA 或 OpenMM 能量分解；
3. FEP+ 对应 pose 的相对自由能结果。

如果 FEP+ 与 FMO 在相同 pose 仍明显不同，主因就是能量模型/自由能定义，而不是 pose。

### 实验 B：全纳入多构象 FMO ensemble

对每个 ligand 预注册相同数量构象，例如 3 或 5 个：

- 不按实验标签挑选；
- 不按结果挑选成功构象；
- 所有构象都必须成功；
- 使用固定算术平均和预注册的 Boltzmann 诊断平均。

若 ensemble 明显改善 Galectin3 且跨 k 稳定，说明构象布居是关键；若仍反向，则说明 FMO 单点相互作用模型是主因。

### 实验 C：系列内相对分析

去掉 17/18 系列之间的固定基线，只比较每个系列内部的相对变化。当前 tPIE 的系列内 Pearson/Kendall 约为 `0.398/0.213`，仍明显低于 FEP+ 的 `0.873/0.664`；因此即使去掉系列基线，FMO 仍未达到 FEP+ 的水平。

## 当前最终判断

Galectin3 的失败最合理的表述是：

> 不是“Galectin3 构象完全错了”，也不是“所有物理方法在该集合上都失败”。当前固定 pose 的 FMO 相互作用能只捕捉了结合自由能的一部分，并且受到配体大小、系列基线、局部几何和缺少构象/溶液态平均的共同影响。FEP+ 能在同一集合上取得高相关，是因为它计算的是相对结合自由能并进行环境与状态采样/修正，而不是简单地对同一个 AB 结构做一次静态能量分解。

目前不能把 FEP+ 的高分直接归因于“构象更准”。必须完成同姿态对照和全纳入多构象 FMO，才能把构象误差与能量模型误差定量拆开。
