# 冻结 OpenBind 百分位规则：原87例和外部靶点迁移审计

日期：2026-10-13。执行脚本 `scripts/evaluate_fmo_percentile_transfer.py`；冻结参考 `runs/fmo87/percentile_transfer_20261013/openbind_reference.json`，逐例数据 `scores.csv`，完整分层结果 `evaluation.json`。此实验**没有重新计算 FMO**，只处理此前已冻结并通过质控的 tPIE；对照中所有实验标签仅在映射冻结后读取。

## 无标签映射与统计口径

选取 OpenBind 成功覆盖 639/639 个结构后、每个化合物平均所有结构的 **490 个 `x=-tPIE`** 作为唯一参考分布。按 `x` 升序保存并记录源文件 SHA256，不读实验 pKD 建表。新配体 `x` 的百分位定义为

`(参考集中小于 x 的个数 + 0.5 × 等于 x 的个数) / 490`，超出范围截到 0 或 1。同值取 midrank，不插值或后验调参。百分位只是无量纲的排序代理，**不是 kcal/mol、pKD 或可预测 ΔG 的校准值**。参考来源 OpenBind 本身曾被用于发现这一思路，所以该集合上的 Pearson 升高是探索性发现，不能算独立外部验证。

原87例的正式评估口径：分别在 CDK2(16)、JNK1(21)、P38(34)、TYK2(16) 内算 Pearson、Spearman、Kendall，然后按例数加权；切勿跨不同靶点混合能量/标签直接算一个全局相关。外部每集均为单一靶点。实验 DG 为负，分数为 `-tPIE`：取 `-DG` 做标签，保持有利值越大越好。Spearman、Kendall 只有在**严格单调且不出现并列**时才保持不变；固定经验 CDF 是阶梯函数，可因大量并列略变。

## 重要解释

固定百分位对**七列既有非参考结果中的五列** Pearson 未能改善（原87 wet、原87 dry19、Galectin3、FXa set4、TNKS2 下降），FXa 主集微升，FXa set3 虽升但仍反向；两列原87是**同一批配体的两个结构臂**，FXa 三列也属同一靶点不同子集，不能算七个独立外部靶点。不能固化成“跨靶点提高 Pearson”的通用方案。尤其 Galectin3 与 FXa 主集分别只有 12/26 和 13/27 个不同的映射值：冻结的 OpenBind 离散 CDF 在外部高分区分辨率不足，出现并列，因此 Spearman/Kendall 有小变化。这不是 FMO 物理项或结合排序被百分位修复的证据。

另作**明确定义为回顾性诊断**的“每个目标内部按当前待测 cohort 重新 rank/N”，Pearson：原87 wet 分层加权 0.5363、dry19 0.5837、Galectin3 0.267、FXa 0.648、TNKS2 0.333。这样做需要预先看到**整个待排队集合所有分数**，一有新配体加入全体原有分数都会变化，并非同一条外部冻结映射。不能把这些诊断结果充作冻结 OpenBind 映射的跨集验证，也不能拿 Pearson 增益声称新实验亲和力信息产生了。

## 部署边界

- 生产管线**保留原始 tPIE 作为默认分数**；百分位列仅是冻结参考的探索性附加报告，不以此更改已冻结结构/QM/质控方案，也不据单靶点回测临时切换。
- 新的无实验标签文件只需 `id,tpie_kcal_mol` 两列；`python scripts/evaluate_fmo_percentile_transfer.py --reference runs/fmo87/percentile_transfer_20261013/openbind_reference.json --scores NEW.csv --output OUTPUT_DIR`，生成 `transformed_predictions.csv`，不读取标签。后续才独立评价。
- 想得到真正跨靶点稳定的 Pearson，须另行预注册参考分布、固定外部靶点与结构流程并做前瞻盲测；不能用本批标签重新拟合非线性校准后仍称“无拟合”。
