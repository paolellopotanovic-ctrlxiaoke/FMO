# 第二阶段结果：结构响应、姿态、氢与数值对照

## 概括

本阶段各项有限对照已执行结束，但 CHK1/BACE 的通用提分及 FXa 新宽侧链候选的稳健收敛未解决。
生产基线仍保留，不将失败的新候选冒充默认工具失败，也不按亲和力标签拼接最高分支。
所有结果属于已知开发集合上的回顾性实验，不能称为新外部盲测。

## 1. 无标签结构响应规则

冻结规则只处理“k10 相对输入引入明显酰胺离平面变形，且局部侧链候选确实纠正它”的机制。
决定函数只接收几何证据及完整几何/QM验收布尔值，不把标签、tPIE 或相关系数输入决定函数。
结果汇总阶段使用已有的独立验收文件（其中包含历史指标），因此不能宣称整个研究环境对标签不可见。

- 13 集合共 270 例中，只有 CDK8 触发且通过完整修复验收。
- CDK8 输出 P / 软P / S / K = **0.705 / 0.699 / 0.697 / 0.511**。
- Galectin3、原 87 的四个靶点等未触发者保留验收基线，Galectin3 S 仍为 **0.544**。
- 这是复用已有基线/候选的结构分支回归，不是又执行了 270 次新 QM。
- 该规则受已知 CDK8 现象启发，不是普适可靠性分类器；尤其不解决 BACE、CHK1 的弱排序。

实现：`core/sidechain_response.py`；逐例证据与回归表分别见
`SIDECHAIN_RESPONSE_RESULTS.zh-CN.md`、`SIDECHAIN_RESPONSE_METRICS.zh-CN.md` 及 JSON。

## 2. 侧链 × 配体氢约束完整消融

每列为软 Pearson / Spearman / Kendall；不选成功子集。

| 集合 | 固定受体，氢约束（基线） | 侧链可动，氢约束 | 固定受体，氢自由 | 侧链可动，氢自由 |
|---|---|---|---|---|
| CHK1 | 0.442 / 0.443 / 0.348 | 0.492 / 0.432 / 0.297 | 0.426 / 0.481 / 0.400 | 0.429 / 0.374 / 0.271 |
| BACE | 0.225 / 0.168 / 0.112 | 0.084 / −0.019 / −0.016 | 0.094 / 0.003 / −0.019 | 0.080 / −0.028 / −0.016 |
| Galectin3 | 0.568 / 0.544 / 0.387 | 0.507 / 0.395 / 0.288 | 0.587 / 0.529 / 0.368 | 0.517 / 0.435 / 0.313 |
| CDK8 | 0.267 / 0.236 / 0.156 | 0.699 / 0.697 / 0.511 | 0.228 / 0.236 / 0.156 | 0.677 / 0.600 / 0.422 |

新增两个氢自由对照分别 **85/85** 完成；原基线和原侧链列复用已验收计算。
只移除配体氢的位置约束，氢数、电荷和连接不变，配体重原子仍 k10；不添加 MM 项到 tPIE。

结论：氢自由对 CHK1 的排序略有帮助，但软 Pearson 下降；BACE 无改善。
侧链与氢自由没有普遍协同增益；不能把操作无条件累加当作“更物理所以更好”。
完整坐标审计及逐例含氢角检查见 `SIDECHAIN_HYDROGEN_FACTORIAL_RESULTS.zh-CN.md` / JSON。

## 3. 固定配体输入重原子的对照

在相同四集合共 85 例固定受体与配体输入重原子，仅优化配体氢：**84/85** 通过。

| 集合 | 原 S | 固定输入重原子 S | 判断 |
|---|---:|---:|---|
| CHK1 | 0.443 | −0.264 | 明显下降 |
| BACE | 0.168 | 不报告子集 | CAT-13i 的 SER96 配对强排斥约 +114 kcal/mol，按原质量门槛拒绝 |
| Galectin3 | 0.544 | 0.539 | 基本相近，但原始 Pearson 明显下降 |
| CDK8 | 0.236 | 0.006 | 下降 |

输入指已制备但未 k10 的姿态，不把含 docked 标注的配体冒充实验晶体姿态。
结果排除了“完全禁止重原子位移就是通用修复”的简单方案。
正确标注的独立结果见 `INPUT_HEAVY_FIXED_CONTROL_RESULTS.zh-CN.md`，不把此对照误称局部侧链处理。

## 4. 配体内部 MM 诊断及实际修复对照

完整 **98/98** 例完成同一配体参数/电荷的内部 MM 单点比较；仅对同分子的几何做差。
孤立输入起点局部最小化有六例未达力阈值，明确标记；不当作溶液自由能或全局最低点。

- CHK1 的候选内部 MM 代价全部下降，排序却未同步改善。降低内部模型能量不足以证明亲和力预测更好。
- BACE CAT-13i 在侧链候选中的内部代价上升 **48.127 kcal/mol**，其中键角项 **41.690**。
- 同例两个氢之间的 H–C–H 角由 **113.70°** 变成 **66.13°**；仅重原子审计会漏掉。
- 移除氢位置约束后，该侧链候选的角仍约 **65.19°**，不能把成因直接归于氢约束。

随后对 85 例统一审计粗大 SP3 H–C–H 异常（80..150°以外），仅 CAT-13i 触发。
按原拓扑与原重原子坐标重建该碳相连氢，仅改两个氢，执行 **1 次新 QM**，其余 **84 例明确复用侧链候选**。
独立核对 FMOXYZ：只有全体系零基索引 823、824 两个 H 坐标变化，重原子、受体和其它坐标不变。
该角变为 **89.40°**，通过粗大角度筛查，但不能称为完整理想几何或完整氢优化。
新 QM 严格收敛，tPIE 为 **−117.591 kcal/mol**。
完整 BACE S 仍为 **−0.020**，未恢复基线 0.168：修复个例几何不等于解决整组错排。

诊断代码：`core/ligand_hydrogen_geometry.py`；条件修复研究入口：`tools/run_flagged_hydrogen_rebuild.py`。
普通氢数、原子索引和重原子保持；同位素氢缺少验证映射时明确拒绝，不静默删除。
这不是生产默认，也不按修复前后相关系数挑构象。

## 5. FXa 数值对照

完整 27 例保持新侧链候选几何、GLN61、口袋、电荷与 QM/PCM：

| 对照 | 完成 | 同几何 tPIE 最大差 | 验收 |
|---|---:|---:|---|
| CNVDMP=0，原 SOSCF | 26/27 | 0.292 kcal/mol | 新增 5b 失败；超过预设 0.1 一致性门槛 |
| CNVDMP=0，DIIS+DAMPH | 0/27 | 无有效比较 | 持续单体 SCF 失败 |
| CNVDMP=0，SOSCF，内层收紧至 1e−10 | 24/27 | 0.364 kcal/mol | 外层周期仍存在；一致性未通过 |

收紧内层精度不能根除外层周期；5b 中变化最明显的是 GLN61 片段，最近六周期能量反复切换约 1.1e−4 Hartree。
尚不能凭此唯一归因到电子态或 PCM 实现。不能删除 GLN61、放宽阈值或拼接不同设置的成功结果冒充完整修复。
这三个新数值候选都不部署；原 FXa 验收基线仍可用。
证据见 `FXA_SIDECHAIN_NUMERICAL_DIAGNOSTICS.zh-CN.md` / JSON。

## 6. 工具结论与未完成问题

本轮新增可执行的结构响应决定、完整受体碰撞复核、含氢角审计、条件 H 重建和匹配消融入口，
有冻结清单、源文件哈希、完整覆盖率及独立结果报告。共享报告器也修正了把其它几何对照错误标注为“4 Å侧链”的标题问题；
重生成标题时独立确认所有 evaluation JSON 内容和哈希未变。

**可以支持：** CDK8 某类制备变形有明确的结构证据与有效侧链对照；用有限响应规则可保留其它开发集合原路径。
**还不能支持：** CHK1/BACE 已普遍提分、所有侧链问题已自动解决、FXa 宽侧链候选已可靠收敛、任意新靶点都能预知预测好坏。
下一阶段需要独立验证化学微观状态/姿态来源/环境与匹配自由能贡献，而不是继续按当前标签增减几何参数。
