# 尺寸与误排：深入核查后的结论

2026-10-21。前一轮在629化合物/778结构上定位疑点，本轮追加全原子氢几何、来源追溯、
晶体受体叠合、误排片段集中度及子集敏感性。没有新QM，没有改变默认分数或删除正式评估样本。
精确证据在 `SIZE_DIAGNOSIS_CONCLUSIONS.json`，复现脚本 `tools/conclude_size_diagnosis.py`。

## 一、可以明确下的结论

1. **不存在已证实的单一通用修复。** 现有证据是尺寸、局部接触、受体构象及化学状态的混合问题，
   不能概括成“氢全错”“水全错”“DI全错”或“归一化MW就解决”。
2. **OpenBind/P38等集合的尺寸趋势确实映射到接触/埋藏及DI，但这不等于正确的实验结合收益。**
   BACE的埋藏面积与MW相关0.820，与实验仅0.089，是最清楚的反例之一。
3. **P38代表性误排不是已查明的补氢错误。** 模型奖励的是几何合理的羟基–ASP氢键；
   静态相互作用优势与实验方向相反，需检验模型中缺失的代价及化学/姿态条件。
4. **OpenBind代表性误排有实质的受体局部构象混杂。** 不能只归给配体立体构型或FMO数值误差。
5. **输入化学状态审计确有缺口，但不是整体排序差的充分解释。** 6例跨表示电荷不同来自原始SDF，
   其中2例为需要化学审查的N-质子化酰胺表示。其它4例是质子化环胺，不能一概判错。

## 二、P38：原先怀疑的O···O接触实际上是什么

对于2ff→2l，实验认为2l更强0.82 kcal/mol，tPIE却认为更弱14.31 kcal/mol。
进一步用源SDF确定配体键连接、用最终PDB确定H位置后：

| 2ff的局部相互作用 | 数值 |
|---|---:|
| 配体羟基O3–ASP112 OD2 | 2.817 Å |
| 羟基H–ASP112 OD2 | 1.838 Å |
| O–H···O角 | 167.4° |
| ASP112侧链质子 | 输入中没有，符合去质子化表示 |
| 同一O···O在k10前 | 2.981 Å |

**明确结论：这不是两个受体氧乱撞，而是配体有真实O–H供体，形成几何合理的氢键。**
2l没有同样的羟基供体近接。因此两者虽然同分子量，化学和相互作用绝不相同。
全原子k10 RMSD仅2ff 0.129 Å、2l 0.104 Å；接触在k10前已经存在，最小化使其略缩短。
不能将此例简单归因于k10造成严重姿态漂移或补氢方向错误。

ASP112命名片段ΔtPIE=+20.638，主要由ES与SOLV变化组成，被其它片段部分抵消。
片段包含FACIO-like主链重分配，不能称这20.638全是单个氢键的能量。
PIEDA的SOLV也不是独立去溶剂化自由能，不能据此完成热力学账本。

**当前最合理的解释范围：** 静态复合物中该氢键使模型明显偏好2ff，但实验不这样排序。
是否由溶液中原有水合、其它构象、微观状态或方法精度导致，尚无单变量实验可区分。
这些是待验证解释，不能写成“已经证明熵/去溶剂化导致误排”。

**对工具：** 保留几何合理的氢键，不做强制“修坏”；增加氢键身份/角度和局部能量敏感性报告。
若做下一轮实验，冻结结构检查原方法能量敏感性，再以预先声明的化学状态/溶液对照验证，
不是看到实验排反就删除氢或调低相互作用权重。

## 三、BACE：锚定区并没有发现明显缺氢

CAT-4k与CAT-4l在ASP93有两处方向合理的N–H···O接触：

| 接触 | CAT-4k H···O / 角 | CAT-4l H···O / 角 |
|---|---|---|
| N2–H→ASP93 OD1 | 1.715 Å / 149.5° | 1.725 Å / 145.2° |
| N3–H→ASP93 OD2 | 1.778 Å / 161.6° | 1.765 Å / 161.0° |

ASP93不带侧链H，ASP289带HD2，两者并非被制备成一模一样的质子化状态。
当前没有证据支持“两个催化ASP全被错设成负离子”或“锚定氢没补上”。
这里未完成pKa或实验pH下微观态分布验证，因此也不能证明现状在热力学上正确。

CAT-13g→CAT-17a中，模型确实得到ES/EX/CT改善，但DI损失7.229与SOLV损失1.673 kcal/mol
超过它们，导致总分方向错误；这是已核实的代数抵消，不是猜测。
CAT-4k→CAT-4l中，水1043贡献差1.360 kcal/mol；它不对应本轮确定的配体–水方向合理氢键，
可能是局部电场/网络变化，不能把这部分当成直接氢键能或立即删除该水。

7个预定义误排配对的最大差异片段分布在ASP93、HOH1043、HOH1044、GLY74、THR293、GLY72，
并不集中在同一个可统一修掉的残基。最大片段占全部绝对片段差的中位数约14.5%，
也说明不能从单个示例推导整集合唯一根因。

**对工具：** 针对水网络与杂环状态的对照有必要，但单纯再补氢或删一个水没有充分依据。
优先解释为什么新增埋藏/DI缺乏实验收益，并用局部化学系列完整验证，不能直接把DI改成零。

## 四、OpenBind：局部受体差异真实存在且来自原晶体

308/318代表同质量、一个立体中心不同的配体；分别使用x7132a/x7247a晶体受体。
对两套受体共有139个CA原子进行刚体叠合：

| 指标 | RMSD |
|---|---:|
| 全部匹配CA | 0.232 Å |
| HIS21重原子 | 0.101 Å |
| ASP39重原子 | 0.115 Å |
| ARG93重原子 | 0.196 Å |
| ASN129重原子 | **3.062 Å** |

两例ASN129的原始晶体→最终结构重原子RMSD均为0.000 Å，坐标原样保留。
这处局部构象差异不是全局坐标没对齐，也不能直接归咎于k10。
在原先53个符合规则的单晶体误排配对中，ASN129是16对的最大绝对片段差来源，
提示该区域值得系统检查，但共享配对不是独立证据，也未证明其构象错误。

**明确结论：308/318不是干净的“只改变配体立体构型”实验。** 模型同时看到了配体与受体局部状态的变化。
现有tPIE只量度当前复合物状态的跨片段相互作用，不显式包含受体从溶液状态进入该构象的自由能代价。
所以更贴合的晶体构象被打成更有利，不能保证实验亲和力也更强。

这是结合本项目结构与分数的机制推断，而不是受体重组自由能已经算出。
也不能直接用固定单受体作为“正确答案”：固定受体也可能排除真实诱导契合，必须预定义对照验证。

**对工具：** 自动进行参考受体叠合、局部构象聚类和片段对应审计；再将统一受体与各自晶体受体
作为明确的比较协议，不能混着输入却将结果当成单变量配体效应。

## 五、化学状态差异：应修审计，但不能夸大提分作用

157/187/188/189/190/297的benchmark SMILES中性，而晶体SDF、上游加氢SDF和当前制备SDF均为+1。
所以不是PDB2PQR或当前结构优化将这些配体错误改电荷；处理链忠实保留了来源状态。

- 157与297具有`C(=O)[NH3+]`的N-质子化酰胺表示，应作为高优先级化学状态审查项。
  这不同于普通质子化胺；本轮不据此替代实验pH/pKa验证，也不宣称一律中性才正确。
- 其它4例的正电在环胺，不能因benchmark画成中性就直接中和。
- 只剔除6例作敏感性诊断，冻结原软压缩分数，MW P由0.542→0.537，FMO P由0.416→0.390。
  **整体差距并未消失，反而扩大。** 因此这6例不是OpenBind整体落后的充分解释。
- 484例结果只是删例敏感性，不能替代正式490例指标，不是修正后的模型性能。

**对工具：** 源结构身份、benchmark标准化身份、计算微观态必须分开记录；检测表示差异并给出依据。
中和或重新质子化必须是经验证的统一规则，不能按实验标签挑态。

## 六、最终判断与优先级

| 优先级 | 工作 | 当前证据与预期 |
|---|---|---|
| 1 | 统一化学身份/微观态来源审计 | 已确认工程缺口；提高解释性和输入可靠性，不承诺修完即提分 |
| 1 | OpenBind受体局部构象与共同参考对照 | 有直接3 Å级局部差异，值得优先检验；不能只归因于配体 |
| 2 | BACE局部化学与水网络的固定结构对照 | 锚定氢合理，贡献抵消明确；可能需模型/溶液改进而非修碰撞 |
| 2 | P38羟基锚定的溶液/微观态与方法敏感性 | 有合理氢键，不应强修；模型收益与实验不一致仍未归因 |
| 始终 | 在近等质量与同系列验证并回归其它集合 | 防止只放大尺寸趋势或牺牲CDK2/TYK2/FAAH |

**结论不是“发现几处坏结构，修掉一定好”。更准确是：当前tPIE含有真实相互作用信息，
但部分集合的静态接触收益与实验结合自由能没有对齐；其中既有输入表示审计问题，
也有晶体受体构象混杂和能量模型范围问题，不能全靠结构修复解决。**

本轮结论仍有边界：尚无新QM对照、受体构象自由能、微观态比例或溶剂自由能，
因此不声称已找到唯一根因，也没有新的提分数字。当前生产分数和正式全部样本指标保持不变。
