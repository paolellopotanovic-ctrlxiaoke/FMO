# 局部配体应变：转为结构审计与修复规则，而非普适加分项

## 决定

可以，也更稳妥。当前跨集合结果已显示“一律 `tPIE + 局部配体应变`”并不稳健：
Galectin3、BACE、CDK8的Spearman分别约0.644、0.318、0.709；
CDK2、CHK1、FAAH分别约−0.662、−0.146、0.315（FAAH匹配tPIE约0.702）。
因此，应把局部应变从生产默认主分数降为结构审计/诊断量，再由有明确物理证据的审计规则修复结构并重算。

**不能**用“这个target历史上加应变指标较好”作为开关；这仍是按target表现选择方法，不能无偏泛化。
也不能仅因应变绝对值大、相关性低、为负，就断言结构坏了并自动改几何。高应变可能是真实构象代价，也可能是MM/QM模型不一致或单个局部最低点的产物。

## 三类结果必须分开

| 审计结果 | 可自动动作 | 分数处理 |
|---|---|---|
| 有可重复的硬结构错误，如原子/化学图不一致、缺氢/错连、严重碰撞、手性/键长/H归属错误、k10诱发且被确认的共轭基团变形、已登记冲突水、受体截断/编号断链 | 仅调用对应已验证的窄修复；修后复审；受体/水处理要求整个target同一个受体版本；个体配体局部修复只作用于有图学触发的case | 重跑该受影响队列；主预测仍报修复后纯tPIE，修复前后配对保留 |
| 优化/SCF/FMO未达到固定收敛门槛 | 从冻结起始结构按预定数值恢复；仍失败则标记未完成、保留日志，不以最后迭代值冒充结果 | 不报部分队列排名，不改变模型容差 |
| 结构和化学检查通过，但局部应变较大/负值、局部极小点敏感或与tPIE尺度相近 | 输出审计警告、能量分布、几何位移及匹配对照；必要时设计同模型物理对照；未经验证不自动“修复” | 纯tPIE作主排序；应变只作为附加诊断列，不自动加进主分数 |

第三类不能直接靠“修复”消除：它并不等同可判错的结构损伤。将应变系数设为0/1再看标签表现，只是隐藏式模型选择。

## 可复用的审计顺序

1. **原始化学图与组分保全**：原子、键级/形式电荷、质子化、立体化学、金属/辅因子/修饰残基/水逐一入账；不认识的化学态fail-closed。
2. **晶体姿势几何**：配体–受体及水氢接触、原子顺序、重原子键几何、结构编号/肽键、对称性映射与姿势对应。
3. **修复前后差分**：精确记录哪一原子/残基改变、修复规则触发证据及输入输出哈希；不触发的case坐标保持不变。
4. **质子化和水审计**：只修明确的冲突氢/错误转移； target-level 水处理统一应用于队列全部配体，不对单例静默删水。
5. **k10之后再审计**：比较输入和k10后的构象，识别新出现的共轭平面破坏、H方向异常或接触恶化；确定性规则修复后必须重新做k10/复审/分片/QM。
6. **QM局部应变审计**：保存结合几何到游离局部最低点的重原子RMSD/最大位移、手性/键长/氢归属、收敛路径和应变；大值或负值只触发诊断，不据此选分数。
7. **盲队列结果门槛**：同一target无论是否触发个体修复，所有case按冻结协议完整覆盖；共享受体、水、口袋规则一致；报告纯tPIE与附加应变对照的P/S/K、失败数和不确定性。

## 当前证据与边界

已观察到BACE的中性共轭NH2在输入近共面而k10后大角度扭出；只重建被几何图规则识别的氢后，原生产纯tPIE的Spearman由0.168升至0.248。
这一证据支持把“原结构到k10后是否新增异常”做成结构审计候选；尚未达到0.6，bootstrap区间包含零，也未进入默认生产钩子。

已实现的主流程本来就有受体化学图审计、输入/后处理几何审计、冲突水氢审计和fail-closed门槛。本轮新增的 `repair_audit` 规则层已经接入主链的 k10 后、QM 前检查：它对整个队列逐配体写出可追溯的 `repair_audit.json`，核对原始配体坐标、k10 后配体坐标、几何门结果和共轭 NH2 候选。默认模式只报告，不改主坐标、不改主分数；`repair-audit --emit-experimental-candidates` 只生成隔离的候选 PDB，必须另建目录重新 k10、重新分片并重新 QM。

因此“改成修复审计规则模式”已经有了工程化入口，但不能把 BACE 的候选修复冒充已验证默认规则：共轭 NH2 规则仍标记为 `EXPERIMENTAL_ONLY_REQUIRES_FULL_K10_AND_QM_RERUN`，直到跨队列完整回归通过。已有的受体、水和图准备修复仍由原有窄规则执行；未知金属、辅因子和共价化学仍 fail-closed。

复用命令：

```bash
fmotpiefinal repair-audit \
  --ligands-sdf RUN/full_target_fmo/ligands_no_properties.sdf \
  --minimized-root RUN/full_target_fmo/minimized \
  --geometry-report RUN/post_k10_geometry.json \
  --output RUN/repair_audit.json
```

如要生成独立、实验性的氢坐标候选，显式追加 `--emit-experimental-candidates`。工具不会覆盖原始 k10 结构，也不会产生或替换主 QM 排名。可选 `--strain-values-json` 仅接收“每个配体名→局部应变数值”的完整映射；负值只能触发能量参照检查，数值大小本身不会触发几何修改或主分数加和。
此轮909结构局部应变迁移测试保持一个固定评分公式，不中途改成审计选择分数；它是为建立反例与正例的完整对照。909例均已执行，但严格验收仅892例成功，17例失败，因此该全队列报告仍为不完整；按预先冻结的规则，不提供FXa、PTP1B、OpenBind的成功子集排序指标。

要把新几何规则接入默认修复，仍需：独立物理/几何理由冻结触发条件；在隔离目录自动触发并按规则修复；完整target重跑；对原87、Galectin3、FXa、OpenBind及已有集合做同版本回归；未触发样本证实逐原子不变；完整失败/覆盖报告。任何步骤都不能按本集合亲和力标签调门槛。当前主链已经完成审计接入，但候选 NH2 坐标修复尚未改变生产默认。

**短结论：主流程先审计并修可证实的结构错误；tPIE保持主分数；局部配体应变只提供诊断，除非未来出现预注册、物理一致且跨队列完整通过的适用性规则。**
