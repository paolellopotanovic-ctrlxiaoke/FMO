# 结构驱动侧链选择：可执行候选流程

## 与统一 4 Å 柔性的区别

统一的是判断规则，而非所有近邻侧链都移动。每个 target 在完整队列上生成一个
冻结的受体–配体接触与保护关系图，选出的残基在该 target 的全部配体中一致使用。
新配体使用已有冻结计划；若需要超出范围，必须显式生成新版本，不能静默改旧规则。

本轮代码是已实现、可执行的研究候选，不是已证明能普适提分的生产默认。
规则开发参考过 CDK8 的已知结构问题，因此本轮属于回顾性方法开发，
不能把 CDK8 的改善再次包装成独立盲测成功。

## 当前自动决策

| 证据 | 动作 |
|---|---|
| 基线 k10 中仍有严重侧链–配体重原子重叠 | 允许相关普通侧链受约束调整 |
| k10 相对输入新引入明显配体酰胺扭曲，附近有侧链接触 | 允许邻接侧链受约束调整 |
| 有距离近邻但没有上述触发 | 保持原基线路径，不增加 QM |
| 可能金属配位、二硫键、显式非肽跨残基共价连接 | 保护相关残基，不用普通侧链松弛处理 |
| PRO 环与固定骨架耦合 | 保持固定；不声称已有环构象采样 |

第一版固定阈值：4 Å 接触图，3.5 Å 酰胺邻接，范德华半径重叠至少 0.6 Å；
双方均为 N/O/S 时另要求距离小于 2.2 Å，避免仅按半径和误标常见极性接触。
酰胺离平面角至少 30°，且较输入增加至少 20°才触发。
这些是工程筛查阈值，不是已校准的自由能模型或已证明最优的参数。
金属距离边只是配位候选，不等同于确认配位键或有效 QM 参数。

仅移动有触发的普通侧链；受体侧链重原子 k2.5、配体全原子 k10，骨架、水及
其它受体原子固定。保持原基线 QM 模型、5 Å 口袋成员、分片和电荷，不改变 tPIE 定义。
不会根据亲和力、既有 tPIE 或最终指标选择残基/阈值/分支。

## 已提供的工具接口

```bash
python -m fmotpiefinal.sidechains \
  --protein prepared.pdb \
  --poses ligands_no_properties.sdf \
  --bound-complexes baseline_complexes.json \
  --output sidechain_decision_graph.json
```

`baseline_complexes.json` 是配体名称到各自基线 k10 复合物 PDB 路径的完整映射。
准备输入必须先通过既有制备与化学审计；这个接口不替代 PDBFixer/PDB2PQR 或参数验证。
输出包含接触边、金属/二硫键/共价保护边、逐残基处理原因、酰胺几何对照、
选择集合、所有来源指纹和冻结计划指纹。同一输出存在不同计划时拒绝覆盖。

执行完整对照：`tools/run_graph_sidechain_transfer.py`。
以已冻结的 12 集合登记加上 CDK8，共 13 集合 270 配体，按用户要求不跑 OpenBind。
无触发集合明确记录 `UNCHANGED_VERIFIED_BASELINE_NO_STRUCTURAL_TRIGGER`，
复用已独立验收的原基线，不虚报为新跑 QM；有触发集合则完整新制备和新 QM。
缺少任一配体成功结果时，不报告该集合的成功子集指标。

## 没有实现或不能据此断言的能力

- 这不是完整 rotamer 库或 MD 构象采样；酰胺角筛查不是配体应变能计算。
- 第一版不自动改变质子化、补做水氢优化，也不随意修补金属/共价模型。
- 保护特殊网络不等于证明其化学状态正确；未知化学仍需原有模型合同。
- 无触发只说明当前两种规则未触发，不证明没有结构问题或亲和力预测一定可靠。
- 原样保留其它集合的分数不算重新验证其 QM 精度，也不是新增提分。
- 自动部署必须等待匹配对照和跨集合回归；目前生产默认不变。

## 较宽松的一层网络对照

按用户要求增加一个独立、更不保守的预定义对照：从直接触发侧链出发，
沿侧链重原子最短距离不超过 4 Å 的几何接触边扩展一层。
仅扩展到原始配体接触区域内的普通侧链；不递归扩展，不解除特殊连接保护，
不因为分数不满意继续增加层数或指定 ASP173 等残基。
几何接触不自动称为氢键或能量耦合。

CDK8 自动选择从两条增加为五条：VAL27、TYR32、VAL35、LYS52、PHE97。
其它集合没有种子触发，因此仍保持基线，而不是为让每个集合发生变化强行松弛。
运行入口：`tools/run_graph_sidechain_network.py`；结果与第一版分开记录。
受体侧链 k2.5、配体 k10、水/骨架固定、原 QM 模型等保持不变。

完整结果：CDK8 的原始 P/S/K 为 0.420/0.394/0.244，较仅两条种子侧链的
0.406/0.297/0.244 改善，但尚未恢复宽范围 16 条侧链对照的 0.684/0.661/0.467。
因此目前只证明这个可执行选择规则比种子规则更有帮助，不能声称已经得到足够的自动选择器。
其它 260 例没有触发，明确复用已验收基线；不是又完成了 260 个新 QM 作业。
