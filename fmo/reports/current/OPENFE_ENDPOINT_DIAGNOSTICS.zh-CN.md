# 已有端态轨迹诊断：BACE 与 CDK8

本报告对应 `matched_openfe_20261022_cuda128/endpoint_structure_diagnostics.json`。
仅分析预先指定的首条边，不代表完整 BACE/CDK8 队列的排序指标。
不扩展全网络 MD，不修改当前快速 FMO 主流程，不使用亲和力选择构象。

## 1. 固定分析规则与工程校验

- 分析快照时已完成的重复；BACE 结合态 2 次、CDK8 结合态 1 次，两者溶液态各 3 次。
- 每次重复均取生产段 1–5 ns，每 0.1 ns 一帧，共 41 帧/端态；不按能量或实验值挑帧。
- 每帧读取交换后的热力学状态，分别取 λ=0 和 λ=1 所在副本；不把固定副本误当作固定配体。
- 根据 OpenFE 导出的 B-factor 分类排除另一端态虚原子；核对真实组分重原子数及保存的 λ 参数。
- 原生 PDB 存在同名虚原子，不能直接交给会折叠同名原子的 PDB 读取器；这里逐行保留原子。
- `analysis_particle_indices` 是非恒等排列，分析轨迹与原始 checkpoint 不同序。逐次核对两者坐标映射及原始 setup 坐标，不静默假设相同顺序。
- 距离使用周期边界；配体按真实端态重原子键图逐键展开，避免以首原子最近镜像折叠长配体。
- 配体内部 RMSD 做自身刚体对齐；姿态 RMSD 另用初始口袋 6 Å 内残基的 CA 对齐。均不做原子对称性优化，原子身份固定。
- 侧链 χ1 使用周期边界和圆统计；水桥只有距离判据，不冒称氢键、去溶剂化自由能或熵。

## 2. 实测结构结果

下面是等长已完成重复的均值；不是独立样本置信区间。
水接触数：水 O 到配体 N/O/S 任一原子小于 3.5 Å 的水分子数。

| 体系/配体 | 结合态内部 RMSD / Å | 溶液态内部 RMSD / Å | 受体对齐姿态 RMSD / Å | 结合态水接触数 | 溶液态水接触数 |
|---|---:|---:|---:|---:|---:|
| BACE CAT-13n | 0.730 | 2.103 | 1.014 | 2.695 | 9.033 |
| BACE CAT-4i | 0.492 | 1.978 | 1.361 | 3.280 | 8.602 |
| CDK8 12 | 0.311 | 1.483 | 0.654 | 1.122 | 8.211 |
| CDK8 20 | 0.442 | 1.455 | 0.773 | 0.732 | 6.691 |

### BACE 的具体发现

1. **不是这对样本的催化 Asp 接触全面消失。** ASP93 对两配体、两重复的最短重原子距离均值约 2.76–2.78 Å，低于 3.5 Å 的帧比例均为 100%；ASP289 均值约 2.95–3.05 Å，接触帧比例约 95–100%。这里只证明近距离接触保持，不能证明相互作用能一定准确。
2. **这两个 Asp 的 χ1 相对稳定。** ASP93 圆标准差约 6–8°，ASP289 约 8–12°；外围 GLN73、LYS70、ILE171 等更活跃。因此没有证据支持只因这条边就再无差别放松整个催化中心。χ1 未穷尽所有侧链自由度。
3. **游离态构象变化明显存在。** 两配体溶液中内部 RMSD 约 2 Å，明显高于结合态；但 RMSD 不是形变能，更不是熵。它支持进一步检查端态构象代价，不能直接将 RMSD 当作惩罚分数。
4. **水接触变化不是两个配体完全相同。** CAT-4i 在结合态平均比 CAT-13n 多约 0.59 个近接触水，而溶液中少约 0.43 个。这个差异只能定位要分析的溶剂环境，不可按水个数乘常数直接加到 tPIE。
5. **当前 MM 自由能也没有解决 BACE 精度。** 已完成两条 bound 重复各自减去三次 solution 均值，约 +2.724/+2.800 kcal/mol；实验 B−A 为 +0.280。方向一致但幅度偏大约 2.4–2.5 kcal/mol。尚非三次重复完成后的最终报告。

### CDK8 的对照

结合态构象较稳定，游离态内部 RMSD 同样较大；这说明“游离态与结合态不同”并非 BACE 独有，也不足以解释为什么某个完整队列排序更差。
第一条 bound 完成重复减去 solution 均值约 −0.496 kcal/mol，实验 −0.450；仅一个配体对，不能推出整个队列的 Spearman 或证明 QM 已超过 FEP。

## 3. 对下一步优化的约束

| 假说/操作 | 当前证据 | 决策 |
|---|---|---|
| BACE 都因催化 Asp 接触丢失而差 | 这条边不支持；接触与 χ1 保持 | 不进行无差别催化位点重建 |
| 游离态构象代价被静态 tPIE 漏掉 | 结构差异存在，尚无对应自由能量化 | 优先分析固定端态代表构象与一致能量差 |
| 水环境影响相对亲和力 | 两配体接触数变化不同，尚非能量证据 | 保留水网络诊断，不加经验水数权重 |
| 全网络加长 MD 就能提高 FMO | 尚无证据，当前成本过高 | 不扩展全网络 |
| 将 RMSD、水数、χ1 相加作为新分数 | 无统一热力学含义与跨集合验证 | 不纳入默认评分 |

后续应优先做可承受的固定帧端态能量诊断，检查配体内部能量、局部水/残基相互作用变化及 QM/MM 差异，而非立即新增大量 MD。
要将其变成自由能修正，仍需一致的总势能差、匹配端态定义与相空间重叠检查；不能把平均 tPIE、平均 RMSD 或接触数称为自由能。
任何候选规则都必须回到完整队列，并回归 Galectin3 等既有集合后才可能进入主流程。

## 4. 复现

在已配置 OpenFE 的 Python 环境内运行：

```bash
PYTHONPATH=src:tools OPENBLAS_NUM_THREADS=1 python tools/analyze_openfe_endpoints.py \
  --run /path/to/matched_openfe_20261022_cuda128 \
  --output /path/to/matched_openfe_20261022_cuda128/endpoint_structure_diagnostics.json
```

该命令只读轨迹，在指定位置写诊断 JSON；没有 GPU 上下文、没有重新模拟、没有亲和力读取，也不会修改生产输入。
报告含分析脚本、冻结协议及拓扑哈希、逐帧状态编号和不完整重复跳过记录。
