# BACE改进实测：2026-10-24

## 结论先行

这轮找到了完整36例上的数值改善，但没有达到Spearman约0.6，也没有证明普适性或自动替换生产默认。
有效候选是“完整tPIE + 同模型配体局部应变”，不是换用ES，不是把新分数仍叫纯tPIE。
所有配体均保留，不拟合权重，不按实验挑选每例构象或每个target的方法。

| 同一方法在各集合应用 | BACE 36例 P / S / K | Galectin3 26例 P / S / K | 当前主流程CDK8 10例 P / S / K |
|---|---|---|---|
| 当前主流程完整tPIE | 0.212 / 0.168 / 0.112 | 0.562 / 0.544 / 0.387 | 0.707 / 0.697 / 0.511 |
| 保留旧tPIE，仅加配体PCM局部应变 | 0.370 / 0.307 / 0.214 | 0.672 / 0.653 / 0.492 | 0.800 / 0.709 / 0.511 |

P均为原始Pearson，不是软压缩Pearson；S为Spearman，K为Kendall tau-b。不同候选不能拼成一行“最优统一方法”。
Galectin3与CDK8是既有开发/回归集合，不能称为未接触的新盲测。

## 具体增加了什么

固定原始k10结合几何、电荷、片段、帽、DFTB3/D3及PCM模型，计算：

`strain = E_PCM(L_bound_geometry) - E_PCM(L_local_minimum)`

`candidate_energy = tPIE + strain`

二者均为能量，单位换算627.5094740631 kcal/mol/Hartree，系数固定为1。
配体从低能局部游离构象转到结合几何时的模型能量代价，使原本有利的相互作用分数变得较不利。
三态对照同时运行完整AB FMO2、A FMO2、单片段L FMO1；不得用选择性FMO的总能量做三态相减。
单片段FMO1仍有完整配体内部量子能量，不是只计算静电。

每例游离配体仅从固定起点作一次局部QM优化。这里没有溶液态构象人口、配体或受体熵，也不称为结合自由能。
结合几何由MM生成、游离几何由QM优化，局部应变可能包含MM/QM几何偏好差异，尚不能全解释为真实结合代价。
没有从多个结果里按实验或数值大小挑选对本例最有利的分数。

## 为什么判断局部参照更值得继续

对相同匹配AB作应变成分诊断：

| 添加到匹配完整tPIE的项 | BACE P / S / K | Galectin3 P / S / K |
|---|---|---|
| 不添加 | 0.232 / 0.177 / 0.110 | 0.511 / 0.489 / 0.337 |
| PCM极化状态的内部能响应 | 0.383 / 0.309 / 0.211 | 0.671 / 0.650 / 0.474 |
| 同配体两几何间PCM总溶剂项变化 | 0.231 / 0.152 / 0.102 | 0.444 / 0.467 / 0.362 |
| 完整PCM局部应变 | 0.385 / 0.318 / 0.220 | 0.639 / 0.644 / 0.468 |

数据支持：这轮改善主要随内部能参照改变，而不是简单叠加更多溶剂项。
内部能是在各自PCM极化状态下求得，不等于独立真空气相形变能；同配体几何变化的溶剂响应也不是整个结合过程的去溶剂化。
这些成分诊断是在观察完整应变组合后设计，不宣称新盲验证，不能据此按target挑内部能或总应变。

## 证据与不确定性

- BACE从匹配tPIE到应变候选，配体对纠正72对、弄反37对；去掉任一例后Spearman改善仍为+0.074至+0.191。
- BACE配对bootstrap的Spearman改善95%区间为[-0.071, +0.351]，仍含0。重复在开发集尝试方法的选择偏差并未被bootstrap消除。
- Galectin3对应配体对纠正31对、弄反10对；去任一例后仍改善。但其bootstrap区间也含0，不能宣传统计上已确立。
- BACE36例、Galectin3 26例和当前主流程CDK8 10例的QM局部最小值均须经过优化器明确收敛及化学几何筛查；筛查不等于真实微观状态或全局最低点证明。
- BACE初轮共享受体标题格式错误，以及CAT-17a优化步数耗尽，均保留原输入/失败日志。仅作格式修复或既有RFO数值恢复，未改变物理模型或放宽收敛阈值。

## 需要避免的两类混淆

1. 全AB三态为避免PCM非极性项实际开关不一致统一用IDISP=0，而旧选择性tPIE保留原设置。因此还单独报告“旧tPIE不变，仅加应变”，隔离全AB/PCM开关混杂。
2. BACE有6例的单独EX与CT分解在全AB/选择性之间出现巨大反向抵消，合计差至多约0.005 kcal/mol。总tPIE、ES、DI与EX+CT和仍可核对，但不能把这些独立EX或CT数值直接解释为真实物理变化。尚未确认其底层实现原因，不据此自动更改解析器或删除样本。

CDK8回归必须接续已被主流程接纳的酰胺修复后结构，基线S=0.697。
另一次使用旧快照的CDK8重现得到旧基线S=0.236，属于历史负对照，不可用它冒充当前主流程。
新增源快照工具根据已验收的结构决策、输入/日志哈希及完整PIEDA加载当前制备态，不查看亲和力或按分数选结构。
Galectin3有两份受体计算实际仅DFTBSK缩进空白不同，是保守文本去重遗漏造成的冗余，不代表采用两种受体模型。
