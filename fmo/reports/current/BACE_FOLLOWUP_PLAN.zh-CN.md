# BACE 后续机制分析：范围、匹配关系与退出标准

## 本轮问题

不是把CDK8修复硬套到BACE，也不是改变ES/SOLV权重。需要区分：k10诱发配体变形、催化羧酸接触适应、水氢方向、质子位置，以及单姿态直接相互作用代理未覆盖的自由能因素。

基准为2026-10-20独立验收的36例主流程：原始Pearson 0.211748、Spearman 0.168180、Kendall 0.111823。FEP公开同名队列为0.624343/0.557022/0.417605，协议和采样成本不同，不能据此把QM单点能视为同一任务。

## 历史质子位置证据不能误用

研究路径 `bace_dyad_20261019/REPORT.md` 和 `independent_provenance.json`：三个新增状态共108项QM独立核验，另一个状态复用既有验收结果。

| 历史方案 | Spearman |
|---|---:|
| 当时基线A | 0.174619 |
| 289_OD1 | 0.143529 |
| 289_OD2：原质子位置的H优化匹配对照 | 0.159037 |
| 93_OD1 | −0.121821 |
| 93_OD2 | −0.127101 |
| 四位置算术均值 | −0.025111 |

该历史基线不是本轮的0.168180版本，因此这些值只比较各自配对历史基线，不能拼成同一协议大表。枚举一个质子的位置不等于完整质子化集合；算术平均也不是人口加权自由能。历史记录确认制备pH=7.4，但实验pH未核实，不能擅自更改默认质子化或宣称已经找准状态。

## 如何判定结论

完整新对照若仍不改善：只能排除“用这些特定操作就足以修好”的解释，不等于排除质子化、结构适应或水的所有影响。不能继续通过看标签反复挑水、挑残基或调权重。

只有得到可测量的结构触发条件、匹配对照的稳定改善，并完成Galectin3和其它集合回归，才新增BACE以外可复用的默认规则。否则保留BACE基线与未解决标记，不声称已达到0.6。

下一阶段若投入，应先核实实验条件/配体微观状态，再设计状态一致、结合态和游离态匹配的采样或热力学循环；不是直接从tPIE减掉一个游离配体总能量。当前两项实验未计算这些自由能贡献。
