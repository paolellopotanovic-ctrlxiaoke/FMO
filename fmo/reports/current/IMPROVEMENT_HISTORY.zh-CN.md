# FMOtpiefinal 改进历史：解决了什么，证据是什么

审计日期：2026-10-20。对象：从早期 tPIE/三态研究到当前独立工具包的已保存历史。

## 1. 先给结论

我们的工作不是把越来越多的能量项不断相加，而是逐渐把一个容易受输入、
结构制备和求解状态影响的计算，变成有统一入口、结构诊断、条件修复、
完整队列验收和结果追溯的工具。**其中只有一部分改动有明确的排序改善证据。**

| 改进类别 | 最重要的已证实收益 | 不能据此声称什么 |
| --- | --- | --- |
| 几何参数 | 原87例匹配对照中，k100→k10 的 tPIE 加权 Pearson 从 0.308 到 0.533 | 所有新靶点都一定提高；k10 是全局最优 |
| 结构制备 | Galectin3 从旧制备的 0.238 提高到新完整制备的 0.559 | PDBFixer、去水或补氢某一步单独造成全部改善 |
| 氢/水诊断 | FXa 固定重原子对照证明水氢方向可明显影响 tPIE；后来加入有边界的碰撞修复 | 所有体系都应恢复源水氢；把所有水/氢删掉更好 |
| 统计后处理 | 固定软压缩在部分集合提高 Pearson，理论上保持排序 | 增加了物理信息、提高了 Spearman/Kendall，或得到了真实自由能 |
| 图与化学修复 | 原始组分不会静默丢失；能定位异常键、氢冲突、封端和特殊组分问题并调用已验证处理 | 图本身能预测亲和力，或所有修复都提高相关性 |
| 严格求解验收 | 区分真实不收敛与解析误拒；最新来源版完整验收 909/909 个结构 | 909/909 都预测准确，或任意化学结构都已支持 |
| 执行与架构 | 两组新鲜成对测试的非QM时间减少约58%–59%；形成可安装、可测试的独立工具 | QM本身加速了相同幅度；独立重命名包又重跑了一次909例 |

**最强的单变量提分证据是 k10；最明显的跨阶段结构改善是 Galectin3，
但属于多因素制备变化；当前并不存在“每次修复都提分”的证据。**

## 2. 如何读这些历史数字

### 2.1 证据与时间边界

本次追溯核对了31份历史报告和9份机器结果，共40份来源。
研究工作目录没有连续的 Git 历史，因此不能伪造“某个 commit 导致某个提升”。
下文日期是保存报告/实验阶段，不保证是每行代码首次写入的日期。

- `H01`–`H31`：历史报告，路径、SHA256及带原始行号的摘录见 `HISTORY_EVIDENCE.json`。
- `J01`–`J09`：原始机器结果，同样登记路径和SHA256。
- 精确指标、配对区间、部分逐靶点对照见 `HISTORY_METRICS.json`。
- 这是一轮只读历史核查；没有把新QM、标签重拟合或事后选优冒充历史实验。
- 原始完整日志和分子资产不复制进当前工具包；摘要不替代完整原始运行材料。

### 2.2 指标口径

下文 `P / S / K` 分别为 Pearson、Spearman、Kendall。
采用亲和力越高分数越高的方向，例如 `score = −tPIE`。
原87例总体数字通常是**各靶点分别计算相关后按例数加权**，不是把不同蛋白
绝对能量混在一起计算的池化相关，也不是不加权宏平均。

“匹配对照”要求同一批配体、同一标签及明确限定的改变；只比较两份不同版本
的最好数字，不构成单变量因果证明。这里的配对 bootstrap 区间也只是开发集
现有样本的描述，不能当成未见靶点的前瞻保证。

### 3.1 早期：先把“究竟算什么”弄清楚

早期同时研究过完整 tPIE、独立 A/B/AB 三态差值、原生 subsystem 分解、
PCM、PBSA、配体单独优化和熵代理。它们不是同一个指标的不同名字。

| 方法 | 实际回答的问题 | 历史结果与决策 |
| --- | --- | --- |
| AB中的完整蛋白–配体 tPIE | 在当前复合物几何和嵌入环境中，跨蛋白–配体片段的相互作用如何 | 作为最终主线；不是完整结合自由能 |
| `E(AB)−E(A)−E(B)` | 三个指定状态之间的电子能量差如何 | 早期原87加权 P/K 为 −0.018/0.043，未优于同期 tPIE 0.479/0.320 |
| 独立B优化后再做三态 | 加入指定模型下的游离配体几何变化 | 87例全部收敛，但 P/K 降至 −0.251/−0.162；没有成为默认项 |
| GAMESS native subsystem analysis | 对同一绑定分析内部的相互作用、单体和溶剂响应作核对/分解 | 代表性6例与独立三态相差约 1.5×10⁻⁶–6.3×10⁻⁶ kcal/mol，排除明显差分符号/解析错误 |

证据：H01、H02。该阶段的主要价值是**验证计算含义与实现一致性**，不是建立
“物理项越多就必然越好”的结论。若A对同一靶点所有配体完全相同，减不减
常数 `E(A)` 不改变该靶点内部排序；不同A则不能这样处理。

独立三态的完整AB FMO2能量不是只取蛋白–配体对，也包括各片段及体系内
二体贡献；tPIE则是所定义的跨蛋白–配体相互作用求和。单片段配体B用FMO1
是因为没有第二个片段可组成二体，并不是刻意把同一个B降成“只算静电”。
当前tPIE主线采用选择性PIEDA，不需要为每个配体独立运行A/B/AB三态。

还有两个必须保留的历史分支：

- **真正气相三态+独立PBSA：** 2026-09-28保存记录仅12/87满足气相三态验收，
  尽管独立PBSA本身87/87通过，也不能报该组合全87相关。另行计算的
  “PCM极化电子项+PBSA”全87诊断代理P/K仅0.00522/0.01736；加转动键数
  代理后为−0.13068/−0.06500。它不是气相法，PCM极化与PB响应也存在模型
  不一致/可能重复计算的解释风险。证据：H29。
- **HF/STO-3G三态：** 一批全87复合物在3600秒预算内全部超时，不能据此
  生成相关；随后延长预算的10月5日保存快照记录24/87完整，CDK2为16/16，
  该完整子集HF三态P/S/K=0.398/0.418/0.333。它们是不同运行快照，不能
  把“0/87”和“24/87”说成同一次运行互相矛盾，也不能冒充HF全87结果。
  当前约0.6的主线指标来自DFTB3/PCM完整tPIE，不是HF。证据：H30、H31。

PCM是在QM中处理连续介质环境；PBSA是另一个极性/非极性溶剂模型的独立
三态计算。当前默认保留DFTB3/PCM，没有把PCM最终能量再随意加一遍PBSA。

例如历史 CDK2/20 的原生三态分解约为：相互作用 −82.691、去溶剂化
+58.181、单体相关 −9.705，总差值 −34.214 kcal/mol。
这只说明该三态定义下各项抵消，**不能把 −34.214 叫作 tPIE，也不能直接把
该分解的“相互作用项”当成所有后续协议下相同的 tPIE**。

当前的完整 tPIE 已包含其PIEDA协议下的 ES/EX/CT/DI/SOLV 等贡献。
再把 ES+SOLV 加回完整 tPIE 不是增加独立物理项，而是改变已有贡献的权重。
早期 ES+SOLV 在原87上曾达到 P/K=0.634/0.508，却在 Galectin3 上达到
−0.538/−0.362；因此最终没有把这个开发集较优的组合替代完整 tPIE。
证据：H03、H13。

### 3.2 先修协议一致性，再讨论参数

早期发现的不是简单“计算慢”，而是有些看似同方法的对照实际上不是同一个
受体、分片或能量定义。主要修正如下。

| 问题 | 修正 | 实际帮助与边界 |
| --- | --- | --- |
| 同一靶点不同配体的口袋不一致 | 从完整冻结队列建立共享口袋、固定分片和受体版本 | 审计发现过82/87例跨旧协议的受体片段不同；消除不公平比较，不保证提分 |
| 自由蛋白优化改变受体 | 固定准备后的受体，主要放松配体 | 旧协议蛋白RMSD中位约1.81 Å，刚体对齐后仍约1.78 Å，确有形变；固定后旧匹配 tPIE 的 P/K 曾从0.479/0.320降到约0.356/0.255，不能隐去退化 |
| 不恰当PIEDA计算设置使分项异常 | 使用与所取相互作用匹配的选择性PIEDA配置并核对分项闭合 | 旧56/87例出现EX/CT绝对值>1000 kcal/mol；代表例tPIE同为−69.034，但EX/CT从约−3583/+3590修正为+8.92/−1.80，修正的是分解解释 |
| 把选择性二体输出当完整AB总能量 | 三态与tPIE输入/解析分开验证 | 防止局部二体求和冒充全AB总能量 |
| 气相对照同时关掉PCM与色散 | 分开检查计算选项 | 最初气相全量仅12/87严格通过，不能把失败的75例忽略后宣称PCM单项优劣 |

证据：H03。**输入一致、分项合理、总能量合法是物理解释的前提，但不等于
对实验排序必然提高。**

### 3.3 k100→k25→k10：最明确的几何参数改进

`k10` 指OpenMM位置约束的力常数为 **10 kJ·mol⁻¹·Å⁻²**，不是最小化10步、
不是采样10个构象，也不是FMO参数。约束项为：

```text
U_restraint = 1/2 × k × Σ |r_i − r_i,reference|²
```

在该主线中，准备后的受体固定，配体在MM势能和位置约束下局部最小化；默认
对配体全部原子施加位置约束。OpenMM内部纳米单位需要将该k数值乘100。

它解决的是：**过硬约束让轻微短接触、氢位置或局部几何不合理难以释放，
量子相互作用对这些小变化又很敏感。** 降低约束允许小幅局部松弛，同时保留
晶体姿态附近的信息。它不是游离配体QM优化，也不能保证唯一局部极小值。

| 原87匹配协议 | 加权P | 加权K | 相对k100重原子RMSD中位数 |
| --- | ---: | ---: | ---: |
| wet、k100 | 0.307692 | 0.246183 | 参考 |
| wet、k25 | 0.462019 | 0.370907 | 0.0703 Å |
| wet、k10 | 0.533264 | 0.412497 | 0.1392 Å |

k100→k10 的加权 ΔP=+0.225572，靶点内配对95%区间为
`[+0.130861,+0.331981]`。不是所有靶点都改善：CDK2 P为0.432→0.871，
JNK1为0.619→0.615，P38为−0.092→0.248，TYK2为0.624→0.694。
证据：H03、H04、J01、J02。**结论：有力支持在已研究主线采用k10，但不支持
对任意新结构承诺相同增益。**

### 3.4 水：从历史dry19走向可复用的碰撞规则

历史比较中，原87在k10下由wet变为P38 dry19、其余靶点不变，P/K从
0.533/0.412变为0.601/0.439。ΔP=+0.067442，配对95%区间
`[−0.058156,+0.187653]`，点估计有利但区间跨零。P38单靶点P约0.248→0.421。
证据：H04、H05、J01。

必须更正两个容易混淆的地方：

1. **历史dry19不是当前完整水处理规则。** 早期该分支是在QM计分时排除19个水，
   当时最小化仍保留这些水；不能说那次实验证明了全流程提前删水的单项效果。
2. **当前规则不是硬编码“P38全部去水”。** 同一套原始水冲突审计在原87上，
   CDK2/JNK1/TYK2原始水为0；P38有343个原始水，其中6个触发新入口严重碰撞，
   不是19个。

当前几何严重接触规则区分元素：H–H距离<0.80 Å，单侧为H时<1.15 Å，
重原子接触距离/范德华半径和≤0.60。氢方向专项修复另有<1.20 Å的候选阈值，
两者不是同一个门。对共享受体系列，将完整队列触发的水ID取并集，形成一个
target-level受体处理计划；计划必须与实际残基、输入指纹匹配，否则停止。

这样解决了“某配体删某个水、另一配体保留它，结果却直接比较”的不一致。
保留合法水与删除严重冲突水是不同决策；氢方向可以修复时也不应直接删整水。
证据：H04–H06；实现见 `pipeline/geometry_audit.py`、`pipeline/water_policy.py`。

### 3.5 PDBFixer、PDB2PQR与完整制备：负责不同问题

| 步骤 | 真正负责的事 | 不负责的事 |
| --- | --- | --- |
| 原始组分/链审计 | 先记录链、残基、晶水、离子、辅因子、封端及配体身份；决定合法输入范围 | 不按实验指标选受体 |
| PDBFixer | 审计缺失重原子/残基与拓扑，按受支持规则修复 | 不保证坐标没有碰撞，不自动理解所有特殊化学 |
| PDB2PQR/PROPKA | 统一蛋白补氢、质子化和电荷制备；当前条件包含pH 7.4 | 不保证对应所有实验pH或所有微观质子态 |
| 配体身份/电荷审计 | 检查显式氢、形式电荷、键和重原子映射 | 不用任意补氢修正错误的化学身份 |
| 水与氢审计 | 处理严重水冲突和可验证的氢方向问题 | 不等于一律dry或一律保留源水氢 |
| k10 | 在准备好的环境中局部松弛配体 | 不是缺失蛋白修复或完整构象采样 |

2026-10-05的完整性审计发现，Galectin3/FXa没有缺失残基、缺失重原子或
非标准残基；PDBFixer对Gal只增加1个氢，后续PQR受体与既有分支逐原子一致。
所以当时**没有PDBFixer单独提分的证据**，也没有把相同deck重复计算算作独立实验。
证据：H07。

2026-10-15随后完成的新完整制备是另一轮比较：

| 数据集 | 旧协议P/S/K | 新完整制备P/S/K | 可以得出的结论 |
| --- | --- | --- | --- |
| 原87 | 0.601/0.602/0.439 | 0.637/0.623/0.460 | 点估计提高；ΔP区间约[−0.012,+0.104]，不能归因单一步骤 |
| Galectin3 | 0.238/0.245/0.174 | 0.559/0.550/0.381 | 完整制备明显改善；ΔP约+0.321，区间[+0.091,+0.586] |
| FXa | 0.622/0.583/0.405 | 0.586/0.563/0.388 | 出现退化；不是“统一新流程处处更好” |

证据：H04、H06、J01、J04。蛋白、氢、水等环节同时有变化，因此Gal的大幅
改善不能只归功于PDBFixer、去水或k10；这也是后续继续拆分FXa原因的动机。

### 3.6 氢方向：找到敏感因素，但没有推出“一刀切”方案

FXa的固定配体重原子对照中，保留同一历史GLN61口袋规则：

| 唯一/主要改变 | P/S/K |
| --- | --- |
| PQR水氢基线 | 0.583453/0.566936/0.393724 |
| 只恢复来源水氢 | 0.618882/0.582812/0.405136 |
| 只改Tyr99氢 | P=0.586973 |
| 只改Tyr225氢 | P=0.583486 |
| 来源水氢加两处Tyr氢 | P=0.621574 |
| 固定重原子、全部氢MM放松 | 0.620108/0.609678/0.427960 |

证据：J03。这说明同一重原子结构下，水氢方向确实能改变tPIE与排序。
但是将“来源水氢”全局转为默认，Gal曾从P/S/K约0.561/0.546/0.387下降到
0.370/0.329/0.245；Gal全部氢放松也只有约0.535/0.475/0.344。
证据：H08、H16。**有用的局部观察不能直接提升为通用默认。**

后来固化的是受限制的处理，而不是全量恢复来源氢：

1. 图定位不同残基间水氢的严重短接触，例如H–H<1.20 Å。
2. 保持水氧及其他重原子不动；仅对被标记的水考虑已验证源氢映射。
3. 验证同一水氧位置、O–H几何和H–O–H角等条件；源映射不合法不能硬套。
4. 若冲突仍在，只对选定水氢作受限修复，冻结其他原子，再复审。
5. 更新结构指纹，接续重新k10、重新分片、QM，而不是沿用旧分数。

FXa代表性的GLN61–水氢接触从约1.04 Å到1.94 Å。一个3例坐标匹配2×2试验：
旧氢+旧数值验收0/3，修氢+旧数值验收0/3，旧氢+严格数值救援2/3，
修氢+严格数值救援3/3。这里支持的是**几何修复与数值求解共同改善覆盖率**，
不是证明修水氢单项就能使全部FXa相关性提高。证据：H16。

旧GLN61排除是QM外缘口袋排除，不是允许从整个蛋白删除GLN61。
该残基曾出现重原子距配体约5.193 Å、H距约3.911 Å的边界差异；当前完整
FXa保留GLN61，并通过已注册的求解路径处理，不能靠硬删残基追求历史最好值。
新图流程FXa原始P约0.614，对照旧候选约0.619；Gal也曾从0.568到0.562。
这些小退化仍保留在记录中。证据：H09、H16、H24。

### 3.9 Pearson软压缩：修尺度，不是增加物理项

对完整队列的 `s=−tPIE`，使用冻结规则：

```text
m = median(s_reference)
sigma = 1.4826 × median(|s_reference − m|)
w = 3 × sigma
soft_score = m + w × tanh((s − m) / w)
```

中位数/MAD参考来源必须记录；可以是冻结参考或当前队列描述性参考，不能
在看到实验标签后逐靶点挑参数。该公式不是简单截断、不是分位数查表，
也不是能量分项的新物理求和。

它解决的是少数极端分数对Pearson线性尺度的影响。正宽度下严格单调，
所以理论上保持同一批预测的Spearman/Kendall；实现还检查浮点饱和是否引入
新的并列，若破坏原顺序就拒绝，零MAD也不会除零强算。

2026-10-16冻结分数上的对照：

| 集合 | 原始P→软压缩P | 排序指标 |
| --- | --- | --- |
| OpenBind | 0.370362→约0.42087 | S/K保持 |
| 原87加权 | 0.636115→约0.64324 | 各靶点S/K保持 |
| Galectin3 | 0.562159→约0.56780 | S/K保持 |
| FXa | 0.618578→约0.62924 | S/K保持 |

证据：H10、J05。CDK2/JNK1/P38的Pearson可小幅下降，原87加权提高不代表
每个靶点提高；最新回归CHK1/CDK8/HIV1也会下降，见第6节。
“固定、计算不读标签”不等于“从未用开发集选择过方法”：3MAD方案是在看过
历史开发表现后形成的，仍需真正冻结后的未见系列验证。

## 5. 当前架构究竟比最初好在哪里

### 5.1 当前计算链

```text
原始受体PDB/mmCIF + 已处于受体坐标系的配体姿态 + 化学身份
  → 原始组分/链/连接审计，防止过滤时丢失信息
  → PDBFixer完整性审计及受支持结构修复
  → PDB2PQR/PROPKA、配体氢/电荷审计
  → 化学图诊断 → 注册局部修复 → 修复后复审/哈希交接
  → target-level水策略及有界氢方向处理
  → 固定准备后的受体，配体OpenMM k10
  → 几何门、全队列共享5 Å口袋、统一分片
  → GAMESS FMO2-DFTB3/PCM，选择性PIEDA取完整跨片段tPIE
  → 最终单体/二体严格收敛、完整覆盖率、注册数值救援
  → −tPIE原始排序 + 冻结规则的单调软压缩 + 证据/耗时输出
```

流水线要求输入姿态在正确坐标系中；结构审计不是通用对接器，也不能凭空
把任意无对应关系的配体构象变成正确结合姿态。对独立晶体记录逐条保留
各自受体是合法模式，不应把它与共享受体同系物系列强制混为一种数据输入。

### 5.2 问题—架构能力—代码位置

## 7. 最终可以怎么向学长解释

1. **几何有直接影响。** 在其余协议保持一致的原87中，放松过硬位置约束到k10
   是最明确的提分因素；它让配体在晶体附近释放局部不合理几何，不是盲目大幅优化。
2. **制备比简单堆项更重要，但归因必须谨慎。** Gal完整制备有明显收益；
   单独PDBFixer在结构本来完整时没有增加有效信息，水氢全局替换还会伤害Gal。
3. **图主要把“问题在哪里、该修什么”工程化。** 已能按规则修一些键、羰基、
   氢冲突与组分表示问题；这些有些只修正确性/覆盖率，不能都算提分成功。
4. **严谨验收不等于强行算过。** PTP1B是字段表示缺陷，HIV1有解析误拒；
   修正后完整通过，但HIV1排序仍差，说明结构/软件正确与模型预测准确是两层问题。
5. **软压缩是尺度处理。** 可改善部分Pearson，不提高同一预测序列的秩相关，
   不能代替物理模型，也没有在所有集合改善Pearson。
6. **架构价值是可重复执行与可审计。** 不再靠历史脚本、人手补例和隐式切换；
   但未知化学和弱相关集合仍有开放问题，不能承诺任意新集合高相关。

最准确的整体结论是：**我们已经把若干确有证据的几何/制备改进和大量
正确性、覆盖率、效率改进固化成统一工具；当前原87/Gal/FXa有较好回归，
但CDK8/BACE/HIV1仍限制跨体系预测能力。下一步应冻结规则，在未参与开发的
系列上验证，而不是以已知标签继续逐target挑最好处理。**
